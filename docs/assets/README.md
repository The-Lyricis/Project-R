# Asset records

Keep provenance and rights information with the relevant asset batch. For a small number of assets, use an adjacent ASSET_PROVENANCE.md. For a larger library, maintain an asset register here and link each entry to its repository path.

Use ../templates/ASSET_PROVENANCE.md for a batch record. Track source, tool and model when known, creation or modification date, human edits, applicable terms, attribution, restrictions, and review status.
